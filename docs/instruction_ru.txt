01 / Установить расширение
Magnific History to JSON
Установка выполняется один раз в том профиле Chrome, где вы работаете с Magnific.
1. Распакуйте архив в постоянную папку
Создайте папку ChromeExtensions в своём профиле Windows и распакуйте в неё архив
расширения. Например:
C:\Users\username\ChromeExtensions\magnific_history2json
username - ваше имя пользователя Windows. Это пример: можно выбрать другую постоянную папку.
Главное - после установки не удалять и не перемещать её.
Внутри magnific_history2json должен лежать файл manifest.json. ZIP предварительно нужно
распаковать через «Извлечь всё…».
2. Добавьте папку в Chrome
Откройте chrome://extensions. В правом верхнем углу включите «Режим разработчика / Developer
mode». Для установки из папки он необходим.
Переключатель находится справа вверху страницы расширений.
Нажмите «Загрузить распакованное расширение / Load unpacked» и выберите папку, в которой
находится manifest.json.
Выбирайте распакованную папку, а не ZIP-архив.
3. Закрепите иконку
Нажмите значок пазла справа от адресной строки Chrome. Найдите Magnific History to JSON и
нажмите булавку рядом с ним. Иконка останется на панели браузера.


02 / Открыть историю и задать даты
Войдите в нужный аккаунт и откройте «Все ресурсы / All assets»:
https://www.magnific.com/app/projects/all-assets
В русской версии раздел называется «Все ресурсы».
Русская и другие локализации подходят. Если запуск сделан из конкретного проекта, расширение
само перейдёт в All assets. Дополнительные фильтры сайта сохраняются и перечисляются в окне
запуска.
Нажмите иконку расширения. В открывшемся окне сразу показаны две точные даты. При
необходимости выберите свои даты через значок календаря рядом с полем.
Пример завершённого периода после нажатия «Предыдущий отчёт». Даты можно изменить.
Отчёт 21 → 20: с 21-го прошлого месяца по 20-е текущего. «Предыдущий отчёт» сдвигает этот
интервал на месяц назад. Конечный день включается в отчёт.
Например, при запуске 25 ноября для ноябрьского отчёта нужны 21.10.2026 - 20.11.2026.
Расширение само выставляет эти точные даты в календаре Magnific.
Если конец периода ещё не наступил, появится предупреждение: данные будут только по сегодня. Для прошлого закрытого
периода нажмите «Предыдущий отчёт».


03 / Запустить и получить архив
Нажмите «Выгрузить»
Расширение применит даты, прокрутит историю, получит превью и сохранит один ZIP. Подтверждать
скачивание каждой картинки не нужно.
Пока собирается история
Оставьте вкладку Magnific активной и окно видимым. При переходе на другую вкладку или
скрытии окна сбор приостановится. После возвращения продолжится с того же места.
Можно работать в другом приложении или браузере, оставив окно Magnific видимым. Если другое
окно полностью скроет его, Chrome может поставить сбор на паузу. Самый простой вариант для
выгрузки без присмотра - оставить окно открытым на некоторое время.
Не закрывайте Chrome и не переводите компьютер в спящий режим. На большом объёме
длительность зависит от истории и скорости сети.
Когда появится «Собираю архив»
Можно переключаться на другие вкладки и приложения: эта часть работы выполняется отдельно от
страницы. Дождитесь сообщения о сохранении файла.
Stop останавливает сбор досрочно и сохраняет уже собранную часть. Для полного отчёта дождитесь
завершения без Stop.
Готовый файл
ZIP автоматически появится в папке загрузок Chrome. Если не нашли его, нажмите Ctrl+J и выберите
«Показать в папке». Для отчёта передавайте ZIP целиком.
В архиве есть JSON и превью из истории. Если встречались загруженные референсы, они лежат в
uploads и отдельно помечены в JSON.
Если нужно разделить большой период
Укажите свои даты и выполните несколько запусков. Например: сначала 01.08.2026 - 31.08.2026,
затем 01.09.2026 - 30.09.2026. Следующий запуск задавайте со следующего дня, чтобы периоды не
пересекались.


04 / Решение проблем
 Ситуация
Что сделать
Иконка не видна
Нажмите пазл Chrome и закрепите расширение булавкой. Проверьте,
что оно включено в этом профиле.
Открыта другая страница
Нажмите ссылку «Открыть Magnific → All assets» в сообщении
расширения. Затем снова нажмите его иконку.
Сбор встал на паузу
Вернитесь на вкладку Magnific и оставьте окно видимым. Во время
сборки ZIP переключаться уже можно.
Пустой или неполный
отчёт
Проверьте аккаунт, даты и дополнительные фильтры сайта. Если
нажимали Stop, повторите запуск без досрочной остановки.
Chrome не находит
файлы
Попробуйте заново подключить распакованную папку через Load
unpacked. Выбирайте папку с manifest.json.
Сайт не подтверждает
даты
Обновите страницу Magnific и повторите запуск. Некоторые слишком
старые даты могут быть недоступны в календаре сайта.
Если проблема возникает при получении картинок
Нажмите правой кнопкой по иконке расширения → «Параметры / Options». Откройте «Решение
проблем» и отметьте «Следующую выгрузку сохранить только в JSON». Запустите выгрузку
ещё раз и проверьте, завершается ли сбор без картинок.
Это диагностика на один запуск. Затем автоматически возвращается обычный отчёт с картинками.
Если появляется кнопка «Сохранить JSON», можно сохранить уже собранные тексты отдельно. Для обычного отчёта после
устранения проблемы повторите выгрузку с картинками.
Установка из папки: официальная инструкция Chrome.
