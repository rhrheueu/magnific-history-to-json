Коллеги, для выгрузки отчёта Magnific скачайте ZIP расширения и распакуйте в постоянную папку, которую не будете удалять — например, C:\Users\username\ChromeExtensions\magnific_history2json.

В Chrome откройте chrome://extensions → включите «Режим разработчика» → «Загрузить распакованное расширение» → выберите эту папку и закрепите иконку.

Затем откройте https://www.magnific.com/app/projects/all-assets, нажмите иконку расширения, проверьте даты отчёта и нажмите «Выгрузить». Пока собирается история, оставьте вкладку Magnific активной. Готовый ZIP появится в «Загрузках».
