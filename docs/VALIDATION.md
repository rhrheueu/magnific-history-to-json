# Проверки версии 2.1

Проверенный набор пройден: 103 автоматических проверки расширения и 20 сценариев в Chrome на macOS. Рабочие выгрузки, промпты, изображения аккаунта и персональные результаты тестирования в репозиторий не включены.

## Автоматические проверки

Запуск: `node --test tests/*.test.js`. Нужны Node.js 20+ и Python 3; дополнительные библиотеки не требуются.

- Корректные и неправильные домены/маршруты; языковые префиксы; отказ на неподдержанных адресах.
- Даты 21–20, переход года, високосные даты, пустые/неверные границы, будущий конец периода, подтверждение календарём. Дополнительные прогоны календарных тестов выполнены с часовыми поясами UTC+14 и America/Los_Angeles.
- Привязка своих рядов к заголовку, виртуализация, несколько рядов, разрывы индексов и отсутствие дубликатов от вложенных элементов.
- Модели отдельно от FPS/пропорций/длительности/качества; разрешение 1.5K; изображения, видео и загрузки.
- Пауза по активности вкладки Chrome и состоянию окна; ошибка канала связи.
- Ошибки HTTP, HTML/JSON вместо изображения, пустой ответ, сеть и таймаут; одна загрузка ZIP; прерывание, освобождение Blob и восстановление фоновой задачи.
- UTF-8, CRC, ограничения ZIP32, одноразовый диагностический режим и резервный JSON без выдуманных локальных путей.

## Проверки Chrome

Проверены посторонний сайт, неправильный раздел Magnific, рабочая ссылка помощи, `/ru/` и `/es/`, запуск из существующего проекта с переходом в All assets, даты по умолчанию, предыдущий отчёт, неверные и пустые даты, повторный клик, Escape/Отмена, точный диапазон, сохранение остальных фильтров, переключение вкладки/возврат, Stop и обычное завершение выгрузки.

Для полученных архивов проверены CRC, статусы завершения, наличие файлов, связи ID и соответствие выборки интерфейсу. Во время паузы позиция ленты не менялась; после возврата сбор продолжился. На свежей тестовой вкладке новых ошибок экспортёра не было.

## Границы проверки

Установка на Windows и работа без авторизации в этой среде не проверялись. Запрет инъекции в служебную страницу Chrome, сетевые сбои и ограничения ZIP32 проверены имитацией. Многогигабайтный архив не создавался. Изменения интерфейса Magnific после выпуска могут потребовать обновления селекторов.
