# Изменения

## 2.1

- Один ZIP с JSON и превью по умолчанию; загруженные референсы отмечены отдельно.
- Точные даты отчёта с заполнением 21-го прошлого месяца — 20-го текущего, с учётом сегодняшней даты.
- Поддержка языковых префиксов, переход из проекта в All assets и ссылка помощи на неправильной странице.
- Исправлена привязка картинок к промптам при виртуализации; все ряды одной группы сохраняются вместе.
- FPS, пропорции, длительность и качество отделены от моделей; поддержано разрешение 1.5K и явные типы видео/аудиозагрузок.
- Пауза по состоянию вкладки Chrome, продолжение при возврате и сохранение неполной выгрузки через Stop.
- Диагностический JSON доступен в настройках на один запуск; резервный JSON не содержит путей к несохранённым картинкам.
- Добавлена инструкция установки в PDF. Проверены 103 автоматических сценария и 20 сценариев Chrome.
