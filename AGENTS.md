# Magnific History to JSON

## Назначение
Chrome-расширение Manifest V3 для выгрузки истории Magnific / Freepik в отчётный JSON и один ZIP с превью.

## Обязательное поведение
- Поддерживать локализованные адреса (`/ru/`, `/es/`, `/pt-br/`).
- По умолчанию: точные даты с 21-го прошлого месяца по 20-е текущего, режим with_images.
- В обычном окне только два поля точных дат и кнопки отчётов 21 → 20; относительные периоды не используются.
- Из любого поддержанного проекта переходить в общую историю All assets. На неподходящей странице показывать активную ссылку на Magnific.
- Фильтровать штатным UI сайта и проверять подтверждение периода до сбора.
- Оставлять другие фильтры сайта; показывать их пользователю.
- С картинками скачивать один ZIP, без картинок — один JSON, через Chrome Downloads с `saveAs: false`.
- Ошибочные/недоступные картинки отмечать в JSON. Не подменять их HTML-файлами.
- Сохранять совместимый массив записей JSON; добавочная сводка находится внутри ZIP.
- При Stop сохранять собранную часть и признак `stopped`.
- Загруженные референсы сохранять в uploads/ и помечать asset_kind: upload; не исключать их из отчёта.
- Диагностический JSON без картинок доступен только в Options → «Решение проблем», действует один раз; в обычном окне режим не переключается.
- При скрытии вкладки сбор истории приостанавливается до visibilitychange; сборка ZIP не зависит от активной вкладки.
- Не переносить в репозиторий рабочие отчёты, личные данные и файлы старого проекта.

## Устройство
`report.js` + `parser.js` инжектятся через `background.js`. Сборка выполняется в `offscreen.html` / `offscreen.js`; `zip.js` пишет ZIP STORE без внешних библиотек. Blob URL освобождается после завершения/прерывания загрузки. Состояние загрузок хранится в `chrome.storage.session` для восстановления фонового процесса.

## Проверки
`node --test tests/*.test.js`, проверка синтаксиса изменённых JS-файлов. Архив проверяется стандартным Python zipfile. Изменения разметки сайта проверять в Chrome. Различать проверку исходников/тестов и реальный прогон установленной версии.
